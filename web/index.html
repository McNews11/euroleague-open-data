Connect it

Claude Code

One command. Runs locally, works on any plan, no account needed.

claude mcp add --transport http euroleague https://YOUR-DEPLOYMENT/mcp

Claude Desktop

Settings → Connectors → Add custom connector, then paste:

https://YOUR-DEPLOYMENT/mcp

ChatGPT

Settings → Apps → Advanced settings → enable Developer mode, then add a custom connector pointing at the same URL.

ChatGPT needs a paid plan for this. Custom connectors are available on Plus, Pro, Business, Enterprise and Edu — not on the free tier. ChatGPT also cannot run local MCP servers at all, which is why this one is hosted. Claude Desktop and Claude Code have no such restriction.

Data quality

Every build runs reconciliation checks and refuses to publish if a blocking one fails: team totals against final scores, player sums against team totals, play-by-play scoring against boxscores, shot counts against attempts.

Known limitations are published rather than hidden. Shot and play-by-play data exist from the 2007 season onward only. In roughly 40% of games the upstream's own period grouping contradicts its event sequence, so those games are flagged as unreliable for lineup analysis instead of being silently used. The server reports what is missing rather than estimating it.

How it works

A rate-limited crawler collects data into a local DuckDB warehouse. The MCP server reads that snapshot and never contacts the upstream API — it holds no HTTP client at all. No amount of traffic here can generate load on Euroleague Basketball's infrastructure.
